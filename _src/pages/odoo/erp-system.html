our rules

Custom code is a liability we keep small.

Every customisation is a cost at the next upgrade. We say no to ones that standard configuration can cover, and build the rest to a few rules.

  • {{icon:check}}Separate modules — never edits to Odoo's own code.
  • {{icon:check}}Version control, staging database, code review.
  • {{icon:check}}Automated tests for anything that posts to accounting.
  • {{icon:check}}Documentation and hand-over — you own the code.
